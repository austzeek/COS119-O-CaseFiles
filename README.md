📢 Weekly Stand Up

Each week, I’ll use this section to share what I’ve been working on, the challenges I’ve encountered, what I’ve learned, and what I plan to focus on next.

Week 1 — Planning and Getting Started

Overview:

This week was mainly about figuring out what I wanted my project to become and how I wanted players to experience it. I decided to create a text-based murder mystery where players investigate five suspects inspired by recognizable villains from movies and television. I started thinking about how the story, player choices, and investigation mechanics could all work together. I also began considering how to organize the code so the project would be easier to expand as I added more features.

Challenges:

One of the biggest challenges was narrowing down my ideas and figuring out where to start. I have a lot of things I’d like to include, but I know trying to build everything at once would make the project harder to manage. I was also still working through how to approach randomized characters and player decisions without making the code unnecessarily complicated.

Accomplishments:

I made progress by establishing a clearer direction for the project and beginning to think more carefully about its structure. I’ve also started looking at problems differently instead of immediately jumping into writing code. Working in C++ has shown me that there can be several ways to accomplish the same thing, and finding the best approach sometimes takes experimenting and a little patience.

Next Steps:

My next goal was to start building the actual game and get the basic menus and interactions working. I also wanted to become more consistent about using my GitHub Project board to organize tasks instead of keeping track of everything in my head. As development continued, I planned to introduce more investigation features while testing along the way.

⸻

Week 2 — Developing the Investigation

Overview:

This week, I made some significant progress on the foundation of Five Faces of Evil. I’ve built the main menu and investigation menus, added five suspects with their own backgrounds and alibis, and started developing their individual dialogue. I’ve also created the initial evidence system, giving players six different pieces of evidence to examine as they investigate the case.

Challenges:

As the project has grown, one of my biggest challenges has been keeping the code organized and making sure each class has a clear responsibility. I’m also working through how to connect the evidence and suspect interactions so they feel like parts of the same investigation rather than separate features.

Accomplishments:

I’ve become more comfortable working with object-oriented programming and understanding how different classes interact with one another. I’ve also made progress with GitHub, improved my testing habits, and spent more time working through problems on my own. Seeing the different parts of the game start coming together has been one of the most rewarding parts of this week.

Next Steps:

My next focus is to make the investigation more interactive by connecting discovered evidence to the suspects and their conversations. I also want to develop the final accusation system so players can use what they’ve learned to decide who they believe committed the murder. Along the way, I’ll continue testing existing features and improving the code as the project becomes more complex.
